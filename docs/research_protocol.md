# 首阶段研究协议

## 目标与证据边界

检验冻结多模态决策模型能否在当前图像与短历史条件下完成局部语义导航，正确停止，并通过简单深度拦截减少危险动作。不使用导航数据更新权重；不声称基础模型预训练未接触导航数据。

相关先例包括 [NavGPT](https://github.com/GengzeZhou/NavGPT)、[VLMnav](https://github.com/Jirl-upenn/VLMnav)、[AO-Planner](https://github.com/chen-judge/AO-Planner)。冻结模型、深度可通行性及分层本身不是新的贡献。首版先收集决策分布与失败轨迹，后续依据证据选择停止判断、恢复机制或推理开销中的一个主问题。

## 冻结的首版行为

四种短动作：前进 0.25m、原地左右转 15°、STOP；相机 256×256、HFOV90°、高度1.25m；代理圆柱半径0.2m、高度1.5m；禁止碰撞滑动。深度使用米制轴向距离，前进检查覆盖宽度为代理半径加0.1m余量的通道。它是避碰启发式，近处盲区、细小物体和低矮障碍的表现需要独立诊断。

模型依据当前图像、至多两张旧图像、最近四条执行反馈与语言目标提出单动作。深度拦截后原地重观察；三次连续拦截结束为 stuck。最多60次决策。只有执行STOP且在预先标定的成功区域中才成功。模型概率及none_probability原样保留，首轮不据此设置自信阈值。

## 任务与预算

三种局部任务为可见目标接近、转向后接近和相似目标区分。36条场景标注固定于实验清单，按一个开发场景、两个留出场景分组。四种实验条件逐项消融；无拦截条件仅在开发场景运行。36条任务中同一目标的多种起点/语言变体视为相关样本，场景族是统计重采样单位。

契约检查最多24次HTTP尝试，接口/短回合阶段全局最多500次；诊断最多7000次，包括重试与轮询。仅使用已经确认的免费额度。模型返回的实际版本必须保存；版本漂移分组报告，不能混合判断推进门槛。未获得密钥时仅能验证软件与仿真。

主要报告任务成功率、到达但未成功比例、错误停止/卡住/服务错误、路径长度、碰撞、拦截率、调用数与端到端决策耗时（含失败）。正确指令与打乱指令的配对差异用于检查语言条件贡献。场景族bootstrap区间仅作探索，两个留出场景不足以支持广泛泛化结论。

## 后续阶段

1. 局部验证通过后加入长指令子目标与进度跟踪；新增记忆与恢复逐项消融。
2. R2R-CE 使用 MP3D 与官方episode，原始0.1.7评测环境独立复现。锁定0.25m、15°、500步、3m成功距离、相机和滑动设置，核对参考基线后报告SR/SPL/NE/OS/nDTW。当前小场景结果不与R2R-CE排行榜直接比较。
3. G1/SONIC 使用独立执行适配器，先在官方MuJoCo路径验证导航短动作到运动学规划器、运动参考、控制器的衔接，测量位移/转角、停止误差、延迟、步态视觉扰动及定位误差，再开展完整导航迁移。

局部任务通过不能证明能替代完整VLN，也不能证明双足机器人真实执行可靠。正式实验前冻结方法、指标、提示词、模型与评测清单，根据探索得到的差异和场景间变异确定规模。
